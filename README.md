# DECON — Website Design & AI-Assisted Prototyping

A responsive website for DECON, a transportation engineering and consultancy business based in Dubai.

[Visit the live website](https://decontransport.com)

## Project overview

The project brings the company's introduction, specialist services, working approach, and contact information into a single-page experience for public transport authorities, operators, and project teams.

This repository presents the design process and live result.

## My role

**Ayşegül Ölge — UI/UX design, visual direction, interaction design, and AI-assisted implementation.**

I directed the page structure, visual hierarchy, responsive layouts, and motion. I used Claude Code to implement and refine the website, reviewed the browser previews, and configured publishing through GitHub and Cloudflare Pages.

## Design decisions

- **Content hierarchy** — Structure the introduction, expertise, approach, and contact sections to make specialist content easier to scan.
- **Responsive layouts** — Refine typography, spacing, and navigation for desktop and mobile screens.
- **Visual direction** — Use transport imagery and consistent typography to communicate the consultancy's field of expertise.
- **Motion** — Use animated process visuals and section transitions to support the page's content.

## AI-assisted workflow

1. Define the page structure and visual direction.
2. Translate design requirements into specific implementation instructions for Claude Code.
3. Review the local browser preview and identify layout, content, and interaction issues.
4. Iterate on responsive behavior, spacing, typography, and motion.
5. Publish the implementation through GitHub and Cloudflare Pages, then review the live result.

Claude Code supported frontend implementation and technical troubleshooting. I guided the design decisions, evaluated the output, and directed revisions.

## Result and current status

The website is live on the client's domain with HTTPS. Updates pushed to the production branch trigger Cloudflare Pages deployments.

Client review and design revisions are ongoing. The contact form currently validates inputs in the browser and displays a prototype message. Message delivery is planned after client approval.
